# Amazon Sales Analysis Dashboard | Power BI

## Project Overview

The **Amazon Sales Analysis Dashboard** is an interactive data visualization project developed using Microsoft Power BI. It provides insights into Amazon sales performance, order trends, product categories, geographic distribution, and order fulfillment.

The dashboard helps users analyze key business metrics, identify sales trends, and understand product and order performance through interactive visualizations and filters.

## Objectives

- Analyze overall sales and revenue performance.
- Track total orders and quantity sold.
- Compare revenue across different product categories.
- Visualize sales trends over time.
- Analyze geographic sales distribution by shipping state.
- Monitor order status and fulfillment performance.
- Build an interactive dashboard for business decision-making.

## Dashboard Pages

The project contains six dashboard pages:

### 1. Amazon Sales Dashboard
Provides an overall summary of business performance through KPI cards, sales trends, category-wise revenue, and a geographic sales map.

### 2. Sales Overview
Focuses on sales performance and revenue trends to help understand changes in sales over time.

### 3. Product Analysis
Analyzes product categories and their contribution to total revenue, helping identify high-performing categories.

### 4. Order Status Analysis
Provides insights into order status distribution and order-related performance.

### 5. Geographic Sales Analysis
Visualizes sales distribution across shipping states to identify geographic sales patterns.

### 6. Fulfillment Analysis
Examines order fulfillment information to understand the distribution of orders across fulfillment methods.

## Visualizations Used

- **Line Chart:** Displays total sales trends by date.
- **Doughnut Chart:** Shows total revenue distribution by product category.
- **Map Visualization:** Represents geographic sales distribution by shipping state.
- **KPI Cards:** Display key business performance metrics.
- **Slicers:** Allow users to filter data by date, category, status, fulfillment method, and shipping state.
- **Navigation Buttons:** Enable movement between different dashboard pages.

## Tools and Technologies

- **Microsoft Power BI Desktop** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – KPI calculations and measures
- **Data Modeling** – Organizing data for analysis

## Interactive Features

- Dynamic filtering using slicers.
- Multiple report pages for detailed analysis.

## How to Use the Project

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open the `.pbix` Power BI project file.
4. If prompted, update the source data path and refresh the dataset.
5. Explore the dashboard using the available slicers and report pages.
